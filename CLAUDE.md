# Investment Simulator — project briefing

Read this before starting any feature. Update it when a feature lands or a decision changes (keep it under ~80 lines).

## Goal
A web app that simulates portfolios and single assets against each other. Educational simulator only: no trading, no investment advice, show a disclaimer.

## Tabs
1. **Simulation / Backtester** — compare portfolios side by side: monthly/annual gain, CAGR, volatility, max drawdown, beta, Sharpe/Sortino, best/worst year, and the difference between portfolios. Growth chart + drawdown chart, with a time-range selector (1M, 1Y, 3Y, 5Y, 10Y, Max, custom).
2. **Portfolio Creator** — build portfolios from stocks, bonds, funds, commodities, etc. Set weights, rebalancing rule (none / monthly / quarterly / annual / drift band), and other options. Show a portfolio profile (sector, geographic concentration, asset mix, characteristics) modelled on Vanguard's VOO profile page. The owner's words were "until the portfolio composition part"; since they asked for sector and geographic mix, which sit inside that section on Vanguard's page, read it as up to and including it (unconfirmed).
3. **Monte Carlo Simulation** — thousands of randomized runs for a selected portfolio: failure rate, probability cones (percentile bands). Stress tests against historical crises (2008 crash, 2020 downturn).

## Finance rules (do not break)
- Always use split- and dividend-adjusted (total return) prices for returns.
- Beta and relative stats are measured against a benchmark (default: S&P 500).
- Crisis windows are the S&P 500's peak-to-trough dates: dot-com 24 Mar 2000 – 9 Oct 2002; GFC 9 Oct 2007 – 9 Mar 2009; COVID 19 Feb – 23 Mar 2020; 2022 3 Jan – 12 Oct 2022.
- Many ETFs are younger than 2008 (VOO launched Sep 2010). Crisis tests need a proxy map (e.g. VOO -> SPY/VFINX) or must say the asset has no data for that period. Never silently truncate.
- Monte Carlo "failure" = portfolio hits zero before the horizon under the chosen withdrawals. State the method used (bootstrap vs parametric) in the UI.
- API keys never ship to the browser or the repo; all Tiingo calls go through the Cloudflare Worker proxy.

## Project map
Add one line per folder/file as it is created, so chats don't need to search. Every `js/x.js` with a `js/x.test.js` is tested by it.
- `index.html` — the whole page: top bar, four sections (`#backtester`, `#creator`, `#monte-carlo`, `#glossary`; all but the first start `hidden`), disclaimer, sources footer. `apple-touch-icon.png` is the home-screen icon.
- `styles.css` — design tokens and all styles. `main` is a size container: narrow-layout rules use `@container`.
- `js/app.js` — tab switching (`#tab`, `#tab/...` or `#tab?...`), tab titles, the side menu and its veil, inflation settings from share links, cross-tab sync (`storage` event), notices for a failed module load, offline and uncaught errors; imports each tab's module.
- `js/data.js` — `PROXY_URL`, `fetchPrices(ticker)` -> `[{ date, adjClose }]` oldest first (all price loading goes through it; CASH, INFLATION and the T-bills are built in the browser), `getJson` (20 s timeout, one retry after a timeout, lost connection or 5xx, plain-words errors with a `retry` flag), `inflation.real`, `inflationNote`, `basisTag`. Saves prices and CPI in the Cache API store `prices-v1`: reused until the next close (and at least 6 h; CPI 24 h), used with a toast when the proxy fails, dropped after 30 days.
- `js/portfolios.js` — saved-portfolio storage (`loadPortfolios`, `savePortfolios` returns false when storage refuses and fires `portfolios-changed`), checks (`portfolioIssue` names the field at fault, `readPortfolio` checks a backup or link entry), and the engine `portfolioSeries(portfolio, prices)` (starts at 100, rebalancing and trading costs, turnover), plus `riskShares`, `effectiveHoldings`, `diversificationRatio`.
- `js/backtester.js` — the Backtester tab. Exports `frame()`, the shared ECharts options (axes, grid, tooltip): build every new chart on it so all charts look alike.
- `js/creator.js` — the Portfolio creator tab: form, models, backup, profile.
- `js/montecarlo.js` — pure simulation maths: `walk`, `simulate` (typed arrays, year by year: 1M runs x 30 years ~10 s, ~60 MB), `everyStart`, `crisisTest`, `historicalRun`, `CRISES`, `PROXIES`/`withStandIns`, `mulberry32` (seeded draws).
- `js/montecarlo-worker.js` — runs `simulate` in a Web Worker so big runs don't freeze the tab (falls back to the main thread if workers fail).
- `js/montecarlo-tab.js` — the Monte Carlo tab.
- `js/stats.js` — pure maths on daily returns, 252 trading days: growth (`totalReturn`, `cagr` from 358 days, `periodReturns`, `rollingReturns`, `holdingPeriods`, `withDeposits`, `xirr`), risk (`drawdowns`, `drawdownEpisodes`, `volatility`, `sharpe`, `sortino`, `billReturns`, `tailRisk`, `moments`, `histogram`, `normalCdf`), relative (`beta`, `correlation`, `relative`, `gapRange`), helpers (`windowOf`, `niceAxis`, `percentile`, `spread`), `summarize`.
- `js/currency.js` — `currencyOf` by ticker suffix (`.L` GBp, `.T` JPY, `.PS`/TBILL PHP, plain letters USD, CASH/INFLATION none), `sharedCurrency`, `currencyLabel`, `currencyNotes`.
- `js/quality.js` — `priceWarnings`: likely unadjusted splits, one-day moves over 40%, gaps over 10 weekdays and stale prices, for the dates shown.
- `js/links.js` — share links: a tab's setup after the `#` (no server sees it; portfolios travel as recipes and clear the address once used), `copyLink`, `offerSave`, and the `exampleCards` on the empty Backtester and Monte Carlo tabs.
- `js/format.js` — shared formatters (`pct`, `num`, `moneyIn(code)`, dates), `show()`, `element()`, `csv`/`downloadCsv`/`download`. Use these; don't add new formatters per tab.
- `js/visuals.js` — `sparkline`, `glyph`/`assetClass` (asset-class icons), `countUp` (rolls from the last value per key), `gauge`, `slidingPill` (every `.segmented`), `toast` (Undo), `tryAgain` (button in a status line).
- `js/fields.js` — `liveField(input, {compact, clear, format})` (tick / shake + reason from min, max, step), `flagField(input, why)` (scrolls to and marks the box at fault), `dropdown(select, {help})` (select-only combobox over a hidden native select, which stays the source of truth). Forms are `novalidate` so these checks run instead of the browser's.
- `js/glossary.js` — `term(label)`: dotted-underline words with a definition popover (tap to open on touch); static headings use `data-term`. Also builds the `#glossary` page (filter box, links like `#glossary/sharpe-ratio`). `{b}` in a definition is the chosen benchmark.
- `js/ticker-search.js` — `attachTickerSearch(input, {multi})`: suggestions under a ticker box (↑↓ Enter Esc) from Yahoo search via the Worker, plus CASH, INFLATION, the T-bills and `extra()` (saved portfolios); any typed symbol is offered as "Use XYZ"; says when searching, nothing matches or search is down. Styles: `.suggest`.
- `js/inflation.js` — `deflate(points, cpi)`, `priceIndex` (the INFLATION line), `cpiFacts` (the "i" note). `js/countries.js` — the 50 countries.
- `js/tbills.js` — PH bills (`tbillSeries`, `fetchTbill`, data in `data/tbills.json`) and the US bill (`readDtb3`, `billYield`, `usTbillSeries`).
- `worker/worker.js` — Cloudflare Worker proxy: `GET /prices?ticker=` (Tiingo; Yahoo for dotted tickers and Tiingo misses; PSE Edge for `.PS`), `/search?q=`, `/cpi?country=`, `/tbill`. `worker/wrangler.jsonc` is its config.
- `improvement-ideas.md` — the 200 rated ideas of 2026-11-21 and whether each was built.
- `design-options.html`, `section-options.html`, `label-options.html`, `logo-options.html` — design explorations (2026-11-15); reference only, not linked.
- `.claude/launch.json` — local preview server (port 8000). `.claude/autopush.sh` — Stop hook that commits and pushes leftover changes with `git add -A`.

## Status of the tabs
- **Backtester — built.** Up to 10 lines, tickers or saved portfolios, as chips (comma, Enter or a suggestion adds one; ✕ or Backspace removes). The list starts empty, with example cards until the first run. Colour follows the line, not its position. A Benchmark box (default SPY, any ticker or saved portfolio) drives beta and every relative figure; "Show on charts" draws it grey and dashed.
  - Period: 1M/1Y/3Y/5Y/10Y/Max (Compare resets to 1Y on purpose), crash buttons (Dot-com, 2008, COVID, 2022; lines without prices for the whole crash are left out and named), From/To, Step (thins the growth and drawdown lines only), log scale, wheel zoom and drag pan, and a caption with the dates and trading days. Only dates every line has are compared; About the data says which line limits them.
  - Blocks: growth of 10,000 (end labels, start line, crisis bands, a takeaway sentence over each chart), head-to-head with a 95% range for the gap, returns by year or month, rolling returns, holding periods (1-20 years), drawdowns (-10%/-20% guides, deepest-point pins, Deepest falls table), monthly heatmap, how returns are spread, risk-vs-return scatter with a benchmark ring, correlation grid, grouped Statistics table (risk-free average, alpha, R², tracking error, information ratio, monthly VaR and expected shortfall; best figure marked; Gap column for two lines), About the data.
  - Also: price warnings, Copy link, Download CSV, Try again after a failed load.
  - Gotcha: don't turn on ECharts `sampling` for lines; it drops different dates per series and the shared tooltip then omits assets.
- **Portfolio creator — built, without sector/regional mix.** Start from a model (60/40, three-fund, Permanent, Golden Butterfly, All Weather) or from scratch: name, holdings with fund names (no cap; each new ticker costs one Tiingo request), weights that total 100% (split bar), rebalancing rule (never / month / quarter / year / drift band), trading cost % per trade. Save checks every ticker has prices and points at the box at fault. Save as copy, Delete with Undo, an unsaved-changes mark with a Discard / Keep editing question, Download my portfolios / Load from file (JSON; restoring the same file twice adds nothing).
  - Profile: header with sparkline and total return; allocation table (share of money vs share of risk) and treemap; correlation grid with effective number of holdings, diversification ratio and near-duplicate pairs; risk and return beside SPY; Regular Deposits (starting amount plus a monthly amount: the fund's time-weighted return vs your money-weighted one); all five rebalancing rules compared, with turnover and cost; Copy link, CSV.
  - Not built yet: sector and regional mix (blocked on the data-source decision).
- **Monte Carlo — built.** Saved portfolio or one ticker; starting amount and withdrawal (capped at 1 trillion), yearly rise, withdrawal rule (fixed or guardrails), contribution (monthly or yearly), adviser fee, years (1-60), runs (1,000 to 1,000,000; default 10,000), how months are drawn, and an optional past crisis to start every run with. Runs are seeded, so comparisons share draws and a link reproduces a run.
  - Methods, stated under the chart: real months one at a time (bootstrap), real months in blocks (stationary bootstrap, 12-month average), bell curve, fat-tailed curve (Student-t, 4 degrees of freedom). Needs 24 full months of history. Balances are nominal unless Inflation-adjusted is on.
  - Results: settings tags, survival dial, percentile tiles, cone (50% and 80% bands, sample runs with failed ones in red, starting-amount line), Keep for comparison, Yearly Spending (guardrails), When Runs Ran Out, Other Withdrawal Amounts, Every Real Start Date, Past Crises, fee and crash-start comparisons. Editing a setting fades results until Run again. Copy link, CSV. Money uses `moneyFit` so huge results fit.
  - Crises: 9 in `CRISES` (1987, 1990, dot-com, 2008, 2011, late 2018, 2020, 2022, 2025; the owner has not confirmed the five beyond the finance rules). Young funds use stand-ins from `PROXIES` (VOO/IVV -> SPY -> VFINX, VTI -> VTSMX, BND -> VBMFX, VXUS -> VGTSX, QQQM -> QQQ), labelled on each row; otherwise the row says there is no data.
- **Glossary — built.** `#glossary` in the side menu: every definition with its formula, a filter box, direct links.

## Commands
- Preview the site: `python3 -m http.server 8000`, then open http://localhost:8000
- Run every test: `node --test js/*.test.js worker/worker.test.js`
- Run the proxy locally: `(cd worker && npx wrangler dev)` — needs `worker/.dev.vars` containing `TIINGO_KEY=...`
- Deploy the proxy: `(cd worker && npx wrangler deploy)`

## Deployment (live; real SPY prices confirmed on the live site 2026-11-14)
- Site: https://mathiascornejo.github.io/Investment-Simulator/ — GitHub Pages serves the `main` branch root of the public repo `mathiascornejo/Investment-Simulator`. Pushing to `main` redeploys the site.
- Proxy: https://investment-simulator-proxy.investmentsimulator.workers.dev — changes under `worker/` only go live after `npx wrangler deploy`. The Tiingo key is the Worker secret `TIINGO_KEY`.
- Caching gotcha: GitHub Pages tells browsers to keep each file for 10 minutes. A browser that visited shortly before a deploy can mix the new page with old scripts and styles (seen 2026-11-14: unstyled form, dead button) until it refreshes. When checking a deploy, reload bypassing the cache before concluding it is broken.
- Git: this repo pushes over HTTPS using the `gh` login, and commits use the GitHub no-reply email (both set in the repo's local git config).
